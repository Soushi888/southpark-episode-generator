# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
bun run dev          # start dev server (port 5173)
bun run build        # production build → build/
bun run preview      # preview the production build
bun run check        # svelte-kit sync + type check
bun run test         # vitest unit tests (run once)
bun run test:watch   # vitest in watch mode
bun run test:e2e     # playwright e2e (requires dev server running on :5173)
bun run scrape       # re-scrape episodes.json from Wikipedia
```

Lint/format with Biome (not eslint/prettier):
```bash
bunx biome check .        # lint + format check
bunx biome check --write .  # auto-fix
```

Run a single unit test file:
```bash
bun run test tests/unit/picker.test.ts
```

## Architecture

**Static SPA deployed to GitHub Pages.** `@sveltejs/adapter-static` with `fallback: 'index.html'`. No server-side logic; all state is client-side.

**Episode data** lives in `src/lib/data/episodes.json` — a static JSON file committed to the repo. It is regenerated by `scripts/scrape-episodes.ts` (Wikipedia API), which must be run manually with `bun run scrape`. The JSON is imported directly into the bundle.

**Picker logic** (`src/lib/picker.ts`) uses the `effect` library (`Effect`, `Random`) for deterministic, composable random selection. Two modes: uniform (`pickEpisodeEffect`) and IMDB-rating-weighted (`pickWeightedEffect`). `pickGhost` is used during the spin animation; `pickEpisode` finalizes the result and marks it seen.

**Svelte stores** (`src/lib/stores/`):
- `episode.ts` — `currentEpisode` and `isSpinning` writable stores
- `filters.ts` — `filterStore` (writable) + `filteredEpisodes` (derived, filters against `seenStore`)
- `seen.ts` — persists seen episode IDs to `localStorage` under key `sp-seen-episodes`

**URL state** (`src/lib/url-state.ts`) encodes/decodes filter state and current episode into query params (`?ep=S05E01&s=1-10&c=Cartman&t=classic`). The page restores state from URL on mount and syncs changes via `replaceState`.

**Styling** uses UnoCSS with `presetUno` (Tailwind-compatible utility classes) plus custom South Park theme colors (`sp-yellow`, `sp-red`, `sp-dark`, `sp-darker`) and shortcuts (`btn-spin`, `card-base`, `pill`) defined in `uno.config.ts`.

**Components** (`src/lib/components/`) are standalone Svelte files. They read from stores directly rather than receiving episodes as props, except `EpisodeCard` which takes an `episode` prop.

## Key Constraints

- `$lib` alias maps to `src/lib/` — use it everywhere in `src/`.
- The `effect` library's `Effect.runSync` is called at pick-time; keep picker functions pure and synchronous-compatible.
- E2E tests expect the dev server at `http://localhost:5173` — start it manually before running `test:e2e`.
- `MAX_SEASON = 28` is defined in `src/lib/types.ts` and must be updated when new seasons are added (alongside re-running the scrape).
