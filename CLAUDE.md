## Commands

```bash
bun run dev          # start dev server (port 5173)
bun run build        # production build → build/
bun run preview      # preview the production build
bun run check        # svelte-kit sync + type check
bun run test         # vitest unit tests (run once)
bun run test:watch   # vitest in watch mode
bun run test:e2e     # playwright e2e (requires dev server running on :5173)
bun run scrape       # re-scrape episodes.json from Wikipedia
```

Lint/format with Biome (not eslint/prettier):
```bash
bunx biome check .        # lint + format check
bunx biome check --write .  # auto-fix
```

Run a single unit test file:
```bash
bun run test tests/unit/picker.test.ts
```

## Architecture

**Static SPA deployed to GitHub Pages** at `/southpark-episode-generator/`. `@sveltejs/adapter-static` with `fallback: 'index.html'`. The `paths.base` in `svelte.config.js` is set to `/southpark-episode-generator` when `NODE_ENV=production`.

**Episode data** lives in `src/lib/data/episodes.json` — 329 episodes across 28 seasons, committed to the repo. Regenerated by `scripts/scrape-episodes.ts` (Wikipedia API) via `bun run scrape`.

**Picker logic** (`src/lib/picker.ts`) uses `Math.floor(Math.random() * episodes.length)` — plain uniform random index into the filtered pool.

**Stores** (`src/lib/stores/`) — all Svelte 5 `.svelte.ts` files using factory functions with `$state`/`$derived` runes. No Svelte 4 `writable`/`derived`:
- `episode.svelte.ts` — `episodeStore.current` and `episodeStore.spinning`
- `filters.svelte.ts` — `filterStore` with per-field `$state`, `filterStore.filtered` (`$derived`), `filterStore.count` (`$derived`), cross-tracks `seenStore.ids`
- `seen.svelte.ts` — `seenStore.ids` (`$state<Set<EpisodeId>>`), persists to `localStorage` under `sp-seen-episodes`

**URL state** (`src/lib/url-state.ts`) encodes/decodes filter state and current episode into query params (`?ep=S05E01&s=1-10&c=Cartman&t=classic`). Synced in `+page.svelte` via `$effect` gated by a `ready` flag — the `setTimeout(() => { ready = true }, 0)` in `onMount` defers past SvelteKit's `initialize()` so `replaceState` is never called before the router is set.

**Styling** — UnoCSS (`presetUno`) + custom South Park theme (`sp-yellow`, `sp-red`, `sp-dark`, `sp-darker`, `font-sp`) in `uno.config.ts`. Global CSS in `src/app.css` includes Bangers font classes (`.sp-logo`, `.sp-heading`), mountain SVG background via `body::after`, and custom range slider thumb styling.

**Layout** — two-column grid on `lg+` screens: left panel (picker + episode card) is `sticky top-8`, right panel (filters + episode list) scrolls naturally. Single column on mobile.

## Key Constraints

- `$lib` alias maps to `src/lib/`.
- All stores are `.svelte.ts` — runes only, no `writable`/`derived` from `svelte/store`.
- All components use Svelte 5 runes: `$props()`, `$state()`, `$derived()`, `$effect()`, `onclick` (not `on:click`).
- `replaceState` from `$app/navigation` must never be called before the SvelteKit router initializes — always gate with the `ready` + `setTimeout` pattern in `+page.svelte`.
- E2E tests expect the dev server at `http://localhost:5173` — start it manually before running `test:e2e`.
- `MAX_SEASON = 28` in `src/lib/types.ts` — update when new seasons are added and re-run scrape.
- GitHub Pages deployment requires `NODE_ENV=production bun run build` for the base path to resolve correctly.
